<h1>Create SSL Certificate</h1>

<!-- wp:betterdocs/api-tryit {"method":"post","path":"/sites/{uuid}/ssl-certificates","refId":7757} /--><!-- wp:paragraph -->
<p>Provisions an SSL certificate for the site. Three providers:</p>
<!-- /wp:paragraph --><!-- wp:list -->
<ul>
<li><strong>xcloud</strong> — Let's Encrypt via xCloud. Requires DNS pointing
at the server, OR an active Cloudflare integration when
migrating from Cloudflare back to xCloud.</li>
<li><strong>custom</strong> — user-supplied certificate body + private key.</li>
<li><strong>cloudflare</strong> — uses the team's Cloudflare integration that
owns the domain's zone. Mapped server-side to the
multi-domain CF SSL architecture.
Switching providers on an already-SSL'd site requires <code>force: true</code>; the previous provider's row is retained as audit history. Returns 202 when the job is dispatched, 409 when generation is already in flight, 422 for pre-flight failures (invalid provider, missing custom cert, DNS not pointing at server, no Cloudflare integration owns the zone, strict-switch without force). Requires the <code>write:sites</code> scope.</li>
</ul>
