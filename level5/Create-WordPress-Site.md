<h1>Create WordPress Site</h1>

<!-- wp:betterdocs/api-tryit {"method":"post","path":"/servers/{uuid}/sites/wordpress","refId":7757} /--><!-- wp:paragraph -->
<p>Provisions a new WordPress site on the specified server. This is an asynchronous operation — the site will be in <code>provisioning</code> status until ready.
<strong>Notes:</strong> - <code>domain</code> is required when <code>mode</code> is <code>live</code>; omit for <code>demo</code> sites (a subdomain is auto-generated) - <code>ssl.provider</code> is required for <code>live</code> mode - If <code>multisite.enabled</code> is <code>true</code>, <code>multisite.type</code> defaults to <code>subdirectory</code> - Credentials (admin password, database password) are returned in <code>auto_generated</code> only once
Requires the <code>write:servers</code> scope.</p>
