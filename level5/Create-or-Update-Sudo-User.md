<h1>Create or Update Sudo User</h1>

<!-- wp:betterdocs/api-tryit {"method":"post","path":"/servers/{uuid}/sudo-users","refId":7757} /--><!-- wp:paragraph -->
<p>Creates a new sudo user on the specified server, or updates an existing one if a user with the same username already exists (idempotent). This is an asynchronous operation — the user will be in <code>updating</code> status until ready. Requires the <code>write:servers</code> scope.</p>
