<h1>Generate Magic Login URL</h1>

<!-- wp:betterdocs/api-tryit {"method":"post","path":"/sites/{uuid}/magic-login","refId":7757} /--><!-- wp:paragraph -->
<p>Returns a short-lived URL that logs the WordPress admin into the site's <code>/wp-admin</code> dashboard without a password. Token TTL is 10 minutes. Synchronous — the first call uploads the xCloud magic-login WP plugin over SSH (subsequent calls skip when plugin status is healthy).
Rate-limited to 30 requests per minute per user. Requires the <code>write:sites</code> scope and the <code>site:magic-login</code> permission. Delegated logins (<code>login_as</code>) additionally require the <code>site:access-magic-login</code> team permission.</p>
