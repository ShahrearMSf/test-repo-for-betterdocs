<h1>Get Domain Update Status</h1>

<!-- wp:betterdocs/api-tryit {"method":"get","path":"/sites/{uuid}/domain/status","refId":7757} /--><!-- wp:paragraph -->
<p>Returns the most recent domain-update status from the site's <code>domainChangeInfo</code> metadata. Read-only — does not trigger a live SSH check. Returns <code>status=idle</code> when no domain update has been recorded. Requires the <code>read:sites</code> scope.</p>
