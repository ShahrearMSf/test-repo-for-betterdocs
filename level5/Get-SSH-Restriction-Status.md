<h1>Get SSH Restriction Status</h1>

<!-- wp:betterdocs/api-tryit {"method":"get","path":"/servers/{uuid}/firewall/ssh-restriction-status","refId":7757} /--><!-- wp:paragraph -->
<p>Returns whether xCloud infrastructure IPs are whitelisted and whether the API caller's IP is whitelisted on the server's SSH firewall. Use before any rule-tightening operation to check for lockout risk. Requires the <code>read:servers</code> scope.</p>
