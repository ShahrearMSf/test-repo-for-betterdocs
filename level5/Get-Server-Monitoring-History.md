<h1>Get Server Monitoring History</h1>

<!-- wp:betterdocs/api-tryit {"method":"get","path":"/servers/{uuid}/monitoring/history","refId":7757} /--><!-- wp:paragraph -->
<p>Returns a time-series of server-wide CPU, RAM, and disk usage sampled from ServerMonitor snapshots. Supports <code>range=24h|7d</code> (default 7d). Requires Pro plan — returns 403 on free plans. Requires the <code>read:servers</code> scope.</p>
