<h1>Install PHP Version</h1>

<!-- wp:betterdocs/api-tryit {"method":"post","path":"/servers/{uuid}/php-versions","refId":7757} /--><!-- wp:paragraph -->
<p>Installs a PHP version on the server. Asynchronous — dispatches to the background queue. Poll <code>/php-versions/available</code> for the final status. Requires the <code>write:servers</code> scope and the <code>server:manage-php</code> permission.</p>
