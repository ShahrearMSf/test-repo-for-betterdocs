<h1>List Site Backup Settings</h1>

<!-- wp:betterdocs/api-tryit {"method":"get","path":"/sites/{uuid}/backup-settings","refId":7757} /--><!-- wp:paragraph -->
<p>Returns the backup settings configured for the site. A site can have multiple entries (typically one local and one remote). The storage provider's credentials are never exposed — only its UUID, provider name, and connection status. Requires the <code>read:sites</code> scope.</p>
