<h1>List Site Snapshots on a Server</h1>

<!-- wp:betterdocs/api-tryit {"method":"get","path":"/servers/{uuid}/snapshots","refId":7757} /--><!-- wp:paragraph -->
<p>Returns the <strong>site</strong> snapshots taken from sites hosted on this server (aggregated across every source site on the server). These are site-level backups/snapshots — this is <strong>not</strong> a server-image or server-level snapshot. Each entry carries the originating site's UUID and name so callers can correlate back to the site. SSH keypair references, raw meta, and logs are stripped. The <code>public_url_token</code> is included only for public snapshots. Requires the <code>read:servers</code> scope.</p>
