<h1>Rescue Site</h1>

<!-- wp:betterdocs/api-tryit {"method":"post","path":"/sites/{uuid}/rescue","refId":7757} /--><!-- wp:paragraph -->
<p>Queues a site rescue job with the selected repair options. Supported options depend on the site type and server stack. Poll <code>GET /sites/{uuid}/events</code> to track completion. Requires the <code>write:sites</code> scope.</p>
