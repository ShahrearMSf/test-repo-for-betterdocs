<h1>Restart a Server Service</h1>

<!-- wp:betterdocs/api-tryit {"method":"post","path":"/servers/{uuid}/services/restart","refId":7757} /--><!-- wp:paragraph -->
<p>Restarts a single server service, addressed by name in the request body (e.g. <code>nginx</code>, <code>lsws</code>, <code>php</code>, <code>redis</code>, <code>docker</code>, <code>supervisor</code>, <code>mysql</code>, <code>mariadb</code>). For PHP servers running multiple versions, supply <code>version</code> to disambiguate. The restart runs synchronously over SSH. Node.js is a runtime and cannot be restarted; PHP cannot be restarted on OpenLiteSpeed servers (they use LSAPI). Requires the <code>write:servers</code> scope.</p>
