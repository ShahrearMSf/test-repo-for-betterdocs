<h1>Trigger Backup</h1>

<!-- wp:betterdocs/api-tryit {"method":"post","path":"/sites/{uuid}/backup","refId":7757} /--><!-- wp:paragraph -->
<p>Initiates an on-demand backup of the site. This is an asynchronous operation — poll <code>GET /sites/{uuid}/events</code> to track completion. <code>type</code> selects the destination: <code>local</code> (default) or <code>remote</code>. A remote backup requires a configured storage provider with a working connection; if it is missing or unreachable the request is rejected with 422 before anything is queued. Requires the <code>write:sites</code> scope.</p>
