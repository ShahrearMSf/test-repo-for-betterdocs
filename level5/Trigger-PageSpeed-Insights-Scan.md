<h1>Trigger PageSpeed Insights Scan</h1>

<!-- wp:betterdocs/api-tryit {"method":"post","path":"/sites/{uuid}/pagespeed/scan","refId":7757} /--><!-- wp:paragraph -->
<p>Queues a new PageSpeed Insights run for both mobile and desktop strategies. Returns 202 with a <code>scan_uuid</code> that links the two strategy runs. Returns 409 if a scan is already running for this site (within the last 10 minutes). After completion, poll <code>GET /sites/{uuid}/pagespeed</code> for the latest results. Requires the <code>write:sites</code> scope and the <code>site:manage-update</code> team permission.</p>
