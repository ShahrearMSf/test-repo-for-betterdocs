<h1>Update Git Deployment Settings</h1>

<!-- wp:betterdocs/api-tryit {"method":"put","path":"/sites/{uuid}/git","refId":7757} /--><!-- wp:paragraph -->
<p>Updates the git deployment configuration for a git-deployed site: tracked <code>git_branch</code>, the push-to-deploy webhook toggle (<code>enable_push_deploy</code>), whether the deploy script runs after each pull (<code>run_after_deployment</code>), the post-pull <code>deploy_script</code>, a custom <code>git_pull_script</code>, an optional <code>restart_services</code> flag, and the site-relative <code>env_file_path</code>. Changing the branch is validated against the connected provider (or a live SSH check) before saving. Only <code>git_branch</code> is required — send it alone to switch branches and deploy without touching the deploy-script settings. Sensitive keys are never returned. Requires the <code>write:sites</code> scope and the <code>site:manage-update</code> permission.</p>
