<h1>Update SSH/SFTP Config</h1>

<!-- wp:betterdocs/api-tryit {"method":"put","path":"/sites/{uuid}/ssh","refId":7757} /--><!-- wp:paragraph -->
<p>Updates the SSH/SFTP authentication configuration for the site. When <code>authentication_mode</code> is <code>public_key</code>, provide <code>ssh_public_keys</code>. When <code>authentication_mode</code> is <code>password</code>, provide <code>password</code>. This is an asynchronous operation. Requires the <code>write:sites</code> scope.</p>
